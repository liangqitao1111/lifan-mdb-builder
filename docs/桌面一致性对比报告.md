## 说明
1. **数据链路一致**：MDB → SQLite 导入（408 孔 / 2904 地层 / 457 标贯 / 616 土工 / 214 颗分 / 796 水位）后，Web 端读取的数据与桌面端直连 MDB 完全一致（否则规则输出不可能全同）。
2. **模块差异均为增强性**：Web 端 rule_engine/spt_corrector/karst/dxf 等文件与桌面版有差异（v23 激活标贯修正计算、v24 R-SPT-001 跨层规则、v36 DXF 参数运行时读取等），但**默认口径（B/硬塑/标准地层关）下输出与桌面版零差异**；差异项为 Web 独有的修复/新规则（测试库无跨层数据，R-SPT-001 无输出）。
3. **复跑方法**：`python work/cmp_full_desktop.py && python work/cmp_full_web.py`（生成 JSON），对比脚本输出 RESULT 行。
4. 项目特色（实测击数判别密实度、塑性封顶硬塑等）在两端一致生效。
