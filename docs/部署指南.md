# 理反 Web · Linux 服务器部署指南（Docker）

> 目标：Linux 服务器（免费/低成本）· Docker 部署 · 生成 MDB 走 GitHub Actions（免费 Windows 虚拟机）
> 前置：已推送远端 `liangqitao1111/lifan-mdb-builder`（main = 最新）

## 一、服务器选购（如尚未购买）

| 方案 | 配置 | 成本 | 适用 |
|------|------|------|------|
| **腾讯云轻量应用服务器**（推荐） | 2C2G / 40G SSD / 4M 带宽 | 新用户约 40-60 元/年（活动价），有免费试用期 | 国内访问快、操作简单、自带安全组 |
| 阿里云轻量/ECS | 2C2G | 新用户约 50-100 元/年 | 同上 |
| Oracle Cloud 永久免费 | 4C24G（ARM） | 0 元（注册可能被拒/实例有回收风险） | 能接受海外节点延迟 |
| 本地旧电脑/NAS | 自备 | 0 元 + 内网穿透（frp 等） | 仅内网/家庭使用 |

**要求**：Linux 发行版任选（Ubuntu 22.04 / Debian 12 推荐）、可安装 Docker、开放 8000 端口。

## 二、服务器初始化

```bash
# 1. 安装 Docker（root 或 sudo）
curl -fsSL https://get.docker.com | sh
sudo systemctl enable --now docker

# 2. 拉取代码
git clone https://github.com/liangqitao1111/lifan-mdb-builder.git /opt/lifan
cd /opt/lifan

# 3. 配置 .env（生成 MDB 必需）
cp .env.example .env   # 若没有该文件，直接创建：
# GH_TOKEN=<GitHub PAT，需 Actions+Contents 权限>
# ADMIN_USER=admin
# ADMIN_PASS=<生产修改>
# AUTH_SECRET=<openssl rand -hex 32>

# 4. 一键部署
bash deploy.sh
```

> GH_TOKEN 获取：GitHub → Settings → Developer settings → Personal access tokens → Fine-grained
> 仓库选 lifan-mdb-builder，权限勾 Actions: Read/Write + Contents: Read/Write

## 三、防火墙 / 安全组

| 云厂商 | 操作 |
|--------|------|
| 腾讯云轻量 | 控制台 → 防火墙 → 添加规则：TCP 8000（来源 0.0.0.0/0） |
| 阿里云 | 安全组 → 入方向 → 添加 TCP 8000 |

## 四、HTTPS（可选，有域名时）

有域名后：
1. 修改 `Caddyfile`：把 `lifan.example.com` 换成你的域名
2. 域名 DNS 解析 A 记录 → 服务器 IP
3. 安装 Caddy：`apt install caddy`（或 Docker 方式）
4. 同目录运行 `caddy run` → 自动签发 HTTPS 证书
5. 无域名：保持 `http://<服务器IP>:8000` 直接访问（自签/明文，内网足够）

## 五、验证

```bash
curl http://127.0.0.1:8000/api/health
# {"status":"ok","title":"理反 Web API","version":"0.2.0","mdb_backend":"mdbtools"}
# Linux 上 mdb_backend=mdbtools（只读解析），在线编辑/统计/DXF/生成 MDB 均基于 SQLite 工作库，不受影响
```

浏览器打开 `http://<服务器IP>:8000` → admin 登录 → 上传 .lz/.mdb → 正常使用。

## 六、运维

```bash
docker compose logs -f lifan-web   # 日志
docker compose restart lifan-web   # 重启
docker compose down && docker compose up -d   # 升级（先 git pull）
# 数据持久化在 Docker 卷 lifan_work（work/ 目录：上传库/工作库/产物）
```

## 七、注意事项

1. **生成 MDB 链路**：服务器只负责触发，GitHub Actions 免费 Windows 虚拟机完成 .mdb 重建并回传产物（约 2-4 分钟）
2. **上传文件**：建议安全组仅放行需要的 IP；生产环境务必改 `ADMIN_PASS`
3. **磁盘**：每次构建 GitHub 仓库 `payload/` 会累积产物（约 2MB/次），长期运行建议定期清理（见 HANDOVER §11）
4. **备份**：Docker 卷 `lifan_work` 定期快照即可全量备份（含工作库与产物）
