## 7. 已知陷阱（改代码前必读）

1. **启动环境**：必须 `envs/default` python + `--app-dir backend`
2. **inlineEdit 拼参**：列名用单引号包裹，勿改回 JSON.stringify
3. **表头断言用 innerText**（textContent 含隐藏图标字符）
4. **filterApply 同步搜索框**（loadOnlinePage 会用搜索框值覆盖 keyword）
5. **冻结列 left 偏移**：20px/80px（对齐 t-row padding）
6. **下载鉴权**：必须走 downloadApiFile/dlStats/dlDxf（fetch+blob 带 Bearer）
7. **config 双模块缓存**：清缓存须同时清 `config` 与 `review.config`（v42 修复，勿回退）
8. **A 类可塑性空隙**：区间键按整数设计（≤3/4~7/...），浮点修正击数落入空隙返回 None 跳过判定（勿改回"坚硬"兜底）
9. **死参数**：CAD复核/手动修正范围等 10 处 Web 未消费（参数中心已标注"未使用"）
10. **push 重试**：GitHub 443 波动，循环重试；fast-forward 被拒时先 fetch + rebase（GitHub Actions 构建产物提交会导致远端领先）
11. **payload 堆积**：每次构建 GitHub 仓库 payload/ 累积约 2MB 产物，长期需清理（不影响功能）
12. **规则异常隔离**：review_strata 单规则异常记录日志跳过（v43），日志在 %APPDATA%\lifan\logs
